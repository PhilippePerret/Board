Ne jamais mettre une commande de test dans le presse-papier (`pbcopy`) de soi-même. Seulement quand Phil le demande expressément, à chaque fois (une demande à un tour ne vaut pas pour les tours suivants).

**Why:** Réaffirmé avec la plus grande fermeté le 2026-08-16 après un pbcopy fait sans demande explicite — cohérent avec `feedbacks/flux-travail-tests.md` ("Lorsque Phil le demande, ET SEULEMENT LORSQUE PHIL LE DEMANDE"), qui disait déjà ça sans que je l'applique.

**How to apply:** Donner la commande en texte normal dans la réponse. `pbcopy` seulement si le message de Phil la demande explicitement pour CE tour précis.
