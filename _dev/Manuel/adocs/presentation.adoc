== Présentation ==

Cette application est pensée pour grandement **simplifier le travail sur des projets quelconque**, que l'on développe un seul projet ou plusieurs de front.

Elle se présente comme un panneau affichant la __carte__ de chaque projet ainsi qu'une liste de __services__ qui sont autant de commandes qu'on peut appliquer au projet.

Cette instllation peut consister à : 

- ouvrir le dossier du projet dans le finder, dans une fenêtre personnalisée (taille, position, type de vue),
- actualiser un fichier versionné et mettre l'ancien dans un dossier d'archives,
- lancer un script qui va chercher une information sur le net,
- ouvrir un fichier dans LibreOffice,
- ouvrir un dossier de code dans VSCode,
- et bien d'autres choses.

On appelle toutes ces opérations des <<services,_services_>> qu'on peut appliquer aux projets.
