Tableau de bord de projets permettant de les contrôler de A à Z. 

Perdre 15 minutes chaque fois qu'on s'installe sur son Mac pour travailler un projet ?… Un jour, j'en ai eu marre ! Alors j'ai pensé à __Super Board__. Une sorte de station de travail qui me permet de tout gérer en cliquant sur des boutons.

Et quand je dis « tout gérer », je pense vraiment à __tout__ gérer. Les possitilités de cette app mac sont infinie. Pas __quasiment__ infinies, non, **infinies**, tout simplement.

Un tout petit tour d'horizon de ses possibilités (mais ce n'est qu'un petit tour d'horizon puisque tout est possible) :

- ouvrir le dossier du projet dans le Finder, le dimension et le mettre dans le type de vue voulue,
- lancer un minuteur pour faire un certain temps de travail,
- programmer en deux secondes une alerte pour aujourd'hui, demain ou un autre jour
- ouvrir un fichier quelconque après l'avoir versionné automatiquement, et le disposer comme on veut dans l'application,
- voir ses tâches Todoist du jour,
- Ajouter ou marquer des tâches Todoist,
- ouvrir n'importe quelle fenêtre dans le Finder,
- faire une recherche (régulière ou pas, complexe ou pas) dans tous les projets
- ouvrir une URL (ou 10) dans le navigateur (je ne suis pas sûr d'être clair… en fait, vous pouvez programmer un bouton, ou 10, pour rejoindre des URL(s) que vous enregistrez… Dès que vous cliquez sur le bouton, votre navigateur préféré s'ouvre et rejoindre l'URL enregistrée. Vous pouvez même avoir un faux projet qui ne consigne que vos URL préférées et chaque bouton vous permet d'en rejoindre une),
- créer le script complexe d'une succession d'actions (par exemple, dans le manuel, vous trouverez la description de l'envoi d'un manuscrit à des maisons d'édition)
- Documentation
  - mettre en place en 2 secondes sa documentation asccidoctor,
  - actualiser sa documentation en un clic,
  - ouvrir sa documentation dans le navigateur de son choix
- Si vous utiliser Git :
  - ajouter rapidement une nouvelle issue
  - lire une liste d'issue et les fermer/épinglé, etc.
  - initialiser les labels
  - committer des fichiers avec confort, sans code,
- Si vous êtes programmeur : 
  - ouvrir le projet dans VSCode ou votre éditeur préféré,
  - ouvrir un Terminal ou iTerm au dossier du projet,
  - un bouton pour le faire mais en jouant la commande que vous avez programmé
- Si vous savez un peu code, vous pouvez lancer un simple script en cliquant sur un bouton (note : aujourd'hui il suffit de demander à Claude, Chat GPT ou autre IA de faire ce script pour vous).

Et bien entendu, vous pouvez faire ça sur autant de projets que voulu, les mettre en standby très facilement et les remettre en route tout aussi facilement
